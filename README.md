# Mydex International — Premium Corporate Website

Complete multi-page React (Vite) frontend for **Mydex International** — global import/export of dry fruits, spices, herbs, seeds, pulses & agro products.

## Tech Stack

- React 18 + Vite
- React Router DOM
- Tailwind CSS
- Framer Motion
- React Icons
- Swiper.js

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:5173`

## Build

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
  components/   # Reusable UI
  layouts/      # Main layout
  pages/        # All routes
  data/         # Products, blogs, nav
  hooks/        # Custom hooks
  styles/       # Global CSS helpers
```
